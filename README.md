# 🧋 What Boba Drink Are You?

A fun, interactive personality quiz inspired by BuzzFeed-style quizzes! Answer a series of multiple-choice questions to discover which boba drink matches your personality.

## ✨ Features

- Interactive quiz experience
- Multiple-choice personality questions
- Progress bar to track quiz completion
- Personalized results based on answer selections
- Six possible boba drink personalities:
  - 🍓 Strawberry Milk Tea
  - 🤎 Brown Sugar Milk Tea
  - 🍵 Matcha Milk Tea
  - 💜 Taro Milk Tea
  - 🧡 Thai Milk Tea
  - 🧋 Classic Milk Tea
- Results screen with personality descriptions
- Option to retake the quiz
- Responsive design for desktop and mobile devices

## 🛠️ Built With

- **HTML5** — Page structure and content
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Quiz logic, answer tracking, scoring, and result generation

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Click **Let's find out!** and take the quiz.

No additional dependencies or installations are required.
